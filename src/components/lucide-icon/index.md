## API

| 属性名      | 描述         | 类型   | 默认值 |

| size        | 图标大小     | number | 24     |
| style       | 图标样式     | object | {}     |
| strokeWidth | 图标描边宽度 | number | 2      |
| color       | 图标颜色     | string | ''     |
